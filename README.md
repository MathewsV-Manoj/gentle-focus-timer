# Gentle Focus Timer

> A timer for people who want to get started without turning their day into a race.

## How to use it

- Pick one task that can fit into a short session.
- Set a 25-minute timer and keep the task visible.
- Take a real five-minute break before deciding what comes next.

## A small note to yourself

Starting small counts. One focused session can be enough for today.
